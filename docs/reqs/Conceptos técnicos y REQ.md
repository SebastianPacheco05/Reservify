### Conceptos técnicos (desde Excel)
> Fuente: `docs/docs/files/reservifyreq.v.1.3.xls.xlsx` → hoja **Conceptos técnicos y REQ.**

- **Python**
  - **Concepto técnico:** Lenguaje de programación principal del backend. Es interpretado, de tipado dinámico (con soporte de tipado estático opcional) y tiene una gran cantidad de librerías para web, bases de datos, seguridad y ciencia de datos. Permite desarrollar rápido y mantener el código de forma legible.
- **FastAPI**
  - **Concepto técnico:** FastAPI es un framework de desarrollo web moderno y de alto rendimiento en Python, diseñado para facilitar la creación de APIs de forma rápida y sencilla. Se basa en las sugerencias de tipos estándar de Python y utiliza librerías como Pydantic para la validación y serialización de datos. FastAPI es conocido por su velocidad y facilidad de uso, permitiendo a los desarrolladores crear aplicaciones con menos código y mayor productividad.
- **Uvicorn**
  - **Concepto técnico:** Servidor ASGI ligero y muy rápido que ejecuta la aplicación FastAPI. Se encarga de recibir las peticiones HTTP, pasarlas a la app y devolver las respuestas. Soporta hot-reload en desarrollo para ver cambios al instante.
- **SQLAlchemy**
  - **Concepto técnico:** Biblioteca usada para conexión y sesiones de base de datos desde el backend. En el proyecto se usa principalmente `Session` y consultas SQL explícitas con `text(...)`, con utilidades ORM puntuales.
- **Pydantic**
  - **Concepto técnico:** Biblioteca Python para validación de datos usando anotaciones de tipos
- **JWT**
  - **Concepto técnico:** JSON Web Tokens son el mecanismo de autenticación. El backend emite tokens firmados con una clave secreta, que el cliente envía en cada petición protegida. python-jose se encarga de firmar, verificar y decodificar estos tokens de forma segura.
- **bcrypt**
  - **Concepto técnico:** Algoritmo de hash para contraseñas. En lugar de guardar las contraseñas en texto plano, se almacena un hash resistente a ataques de fuerza bruta. Bcrypt incluye un “coste” configurable que hace más lento el cálculo del hash (y por tanto más difícil de romper).
- **python-dotenv**
  - **Concepto técnico:** Carga las variables de entorno definidas en un archivo .env (como claves secretas, URLs de base de datos, credenciales de correo). Esto separa la configuración sensible del código fuente y facilita cambiar entornos (desarrollo, pruebas, producción).
- **SMTP**
  - **Concepto técnico:** Conjunto de funciones que usan el protocolo SMTP para enviar correos electrónicos (confirmaciones, recordatorios, contacto). Normalmente se conecta a servidores como Gmail u otros proveedores, autenticándose con usuario y contraseña seguros.
- **POSTGRESQL**
  - **Concepto técnico:** PostgreSQL es un sistema de gestión de base de datos relacional (RDBMS) de código abierto, ampliamente reconocido por su fiabilidad, flexibilidad y capacidad para manejar grandes cantidades de datos. Se considera una de las bases de datos relacionales de código abierto más avanzadas del mundo.
- **TypeScript**
  - **Concepto técnico:** Superconjunto tipado de JavaScript. Añade tipos estáticos opcionales, lo que ayuda a detectar errores en tiempo de compilación, mejorar el autocompletado y hacer el código más mantenible en una base de código grande como este frontend.
- **React**
  - **Concepto técnico:** Es una biblioteca Javascript de código abierto diseñada para crear interfaces de usuario con el objetivo de facilitar el desarrollo de aplicaciones en una sola página.
- **VITE**
  - **Concepto técnico:** Vite es una herramienta de desarrollo para el frontend (parte del sitio web que el usuario ve) que busca acelerar el desarrollo y la construcción de aplicaciones web modernas. Es conocido por su velocidad, tanto en el desarrollo como en la compilación final, y su facilidad de uso.
- **React Router**
  - **Concepto técnico:** Librería de ruteo para React en aplicaciones web. Permite definir rutas (URLs) que cargan páginas o componentes específicos, soporta rutas anidadas, parámetros, protección de rutas (según rol/estado de login) y navegación programática.
- **TAILWINDCSS**
  - **Concepto técnico:** Tailwind CSS es un framework CSS "Utility-first" que proporciona un conjunto de clases de utilidad para diseñar interfaces de usuario de forma rápida y eficiente. En lugar de definir componentes predefinidos como Bootstrap, Tailwind se centra en clases específicas para estilos individuales, como colores, espaciado, fuentes, sombras, etc. Esto permite a los desarrolladores crear diseños personalizados y mantener un código CSS más limpio y optimizado.
- **tailwindcss-animate**
  - **Concepto técnico:** Extensión de Tailwind que añade clases de animación ya definidas (fade, slide, etc.). Simplifica añadir transiciones y animaciones sin tener que escribir keyframes manualmente.
- **Framer Motion**
  - **Concepto técnico:** Librería de animaciones para React muy potente. Permite animaciones suaves, gestos (drag, hover, tap) y transiciones complejas entre componentes o páginas, con una API declarativa e integración estrecha con React.
- **Radix UI**
  - **Concepto técnico:** Colección de componentes de interfaz “sin estilos” pero accesibles (modales, menús, tooltips, etc.). Aporta la parte compleja de accesibilidad, manejo de foco, teclado, ARIA, etc., y el proyecto se encarga de aplicar el diseño visual (con Tailwind, por ejemplo).
- **Shadcn/ui**
  - **Concepto técnico:** Conjunto de componentes construidos sobre Radix UI y Tailwind. Ofrece componentes pre-armados y estilizados (botones, inputs, tarjetas, diálogos) listos para usar y muy coherentes, pero que siguen siendo personalizables a nivel de diseño.
- **Lucide React**
  - **Concepto técnico:** Paquete de iconos en formato React (SVG). Proporciona una amplia colección de iconos limpios y modernos que se integran fácilmente con Tailwind (p. ej. para tamaños y colores).
- **Leaflet**
  - **Concepto técnico:** Librería de JavaScript para mapas interactivos. Permite mostrar mapas, marcadores, popups, capas, etc. Es ligera y se integra bien con tiles de proveedores como OpenStreetMap.
- **React Leaflet**
  - **Concepto técnico:** Envoltura de Leaflet para React. Convierte las APIs de Leaflet en componentes React (<MapContainer>, <Marker>, etc.), para que puedas manejar el mapa dentro del mismo flujo declarativo de React.
- **IMAP**
  - **Concepto técnico:** IMAP (Internet Message Access Protocol) es un protocolo estándar de correo electrónico que permite acceder y gestionar mensajes directamente en el servidor desde múltiples dispositivos simultáneamente.
